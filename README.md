# Box Em Like A Fish

A browser-based voxel-style first-person shooter built with the PlayCanvas engine.

## Features
- Fast-paced FPS gameplay with voxel elements
- Multiple weapons including SMG and Sniper
- Interactive ammo crates
- Enemy AI systems
- Building and destruction mechanics
- Environmental effects (storms)
- Cross-platform input support

## How to Play
1. Open `index.html` in a modern browser.
2. Use WASD to move, mouse to look, left click to shoot.
3. R to reload, number keys for weapons.
4. Approach ammo crates and press E to refill.
5. Build with voxel tools.

## Controls
- Movement: WASD / Left Stick
- Aim/Look: Mouse / Right Stick
- Shoot: Left Mouse / RT
- Reload: R
- Weapon Select: 1-4 or Mouse Wheel
- Jump: Space
- Build Mode: B
